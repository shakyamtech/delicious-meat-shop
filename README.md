# Delicious Meat Shop (The Meatly)

A web application designed for Delicious Meat Shop (The Meatly) to manage inventory, display product catalogs, and handle customer sales.

## Tech Stack

### Frontend & Framework
- **Next.js (v16)**: Modern React framework supporting server components and Client-side navigation.
- **React (v19)**: User interface library for interactive components.
- **TypeScript**: Strongly-typed programming language built on JavaScript.

### Backend & Database
- **Supabase**: Database and Backend service providing PostgreSQL data storage.
- **Supabase Client SDK**: Javascript library to interact with database tables, handle queries, and sync updates.

### Utilities
- **Nepali Date Converter**: Utility library to convert Gregorian date formats to Nepali Bikram Sambat (B.S.) dates.
